# Contributing to LocalRouterLLM

Thank you for your interest in contributing to **LocalRouterLLM**! We welcome contributions from developers, researchers, and AI enthusiasts of all skill levels.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs
- Check the [existing issues](https://github.com/wTHE-HUNTERw/LocalRouterLLM/issues) before opening a new report.
- Include detailed hardware specifications (GPU, VRAM, CPU, RAM) and the exact client (OpenCode, Continue, etc.) you used.
- Include terminal logs or error traces.

### 2. Suggesting Features & Client Support
- Open a feature request issue describing the use case.
- If you want integration with a new AI coding tool (e.g. Cursor, Roo-Code, Claude Code), please provide example config payloads.

### 3. Submitting Pull Requests
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/awesome-feature`
3. Commit your changes: `git commit -m 'feat: add support for dynamic slot cache'`
4. Push to the branch: `git push origin feature/awesome-feature`
5. Open a Pull Request on GitHub.

---

## 📝 Code Style & Guidelines
- Follow [PEP 8](https://peps.python.org/pep-0008/) style guidelines for Python code.
- Avoid introducing heavy dependencies; keep LocalRouterLLM lightweight and fast.
- Test your changes on Windows with and without GPU offloading.
