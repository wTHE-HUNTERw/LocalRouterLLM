# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a high priority for **LocalRouterLLM**. If you discover a security vulnerability or exploit:

1. **Do not disclose the issue publicly** on GitHub issues, forums, or social media.
2. Please open a private report or contact the maintainer directly via GitHub profile: [@wTHE-HUNTERw](https://github.com/wTHE-HUNTERw).
3. Provide detailed steps to reproduce the issue.

We will acknowledge receipt of your report within 48 hours and work on a fix promptly.
